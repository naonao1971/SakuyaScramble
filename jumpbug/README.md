# 咲耶ジャンプバグ（プロトタイプ）

レトロゲーム「ジャンプバグ」風の横スクロール。⌐◨-◨カーは地面や屋根に触れるたびに勝手に跳ねる。
画面は本家と同じく**強制スクロール**で、一定の速さで勝手に進む。何も押さなければ車は画面について走り、
→で前へ、←で後ろへずれる。壁と画面の左端にはさまれるとミス。
CNPを拾いながらゴールの鳥居を目指す。公開URLは `https://sakuya.naoblock.jp/jumpbug/`。

- 単一ファイル（`index.html`）。画像は本家の `../assets/cnp/*.png`（CNP 11体）と `../image01.png`（咲耶の表情）を使う
- 音はWebAudioで生成しているので、音声ファイルは不要

## 操作

| 入力 | キーボード | スマホ |
| --- | --- | --- |
| 加速・減速 | ← → / A D | 画面の左半分を押したまま左右に倒す |
| ジャンプ（押している間は高く跳ぶ） | SPACE / ↑ / Z | 画面の右半分を長押し、右の JUMP、またはスティックを上に倒す |
| ショット | X | SHOT |
| 自動連射の切り替え | V | SHOT の左の小さいボタンを長押し（600ms） |
| 一時停止 / 音 | P / M | 右上のボタン |

**自動連射**は咲耶スクランブルと同じ作り。スマホでは最初からオン（PC はオフ）で、ジャンプに集中できる。
ボタンはかすめて誤爆しないよう長押しで切り替え、押している間は琥珀色が下から満ちる。短いタップでは切り替えず、やり方を画面に出す。

ボタンの中身はすべて 11×11 ドットのアイコン（`index.html` の `ICONS`）。SHOT と JUMP は同じ大きさ。

ジャンプは押した瞬間に手応えが返るようにしてある。跳ねた直後に押せばその場で大ジャンプ、
落ちている最中に押せば次の着地で大ジャンプ（予約）。短く押しただけでも `JUMP_HOLD`
フレームぶんは長押し扱いになり、長く押すほどさらに高く跳ぶ。

**連続ジャンプ:** 空中でジャンプを押すと、その場でもう一度跳ぶ。着地までに `AIR_JUMPS`（既定2）回まで。
使い切ってから押すと、次の着地で大ジャンプする予約になる。空中ジャンプの強さは `PHYS.airJump`。
目安（地面から上がる高さ）: 何もしない約70px / 空中1回で約175px / 空中2回で約280px。

スマホの移動は姉妹作「咲耶Nounラリー」と同じ**浮動式バーチャルスティック**。
左半分のどこでも、触れた場所にスティックが出る。最初に倒すまでは左下に点線の影と
「左半分のどこでも押したまま倒す」の一行を出す（走り直すたびに出し直す）。
プレイ中は iOS のピンチズームを打ち消す（1本指の動きは打ち消さない）。
JUMP/SHOT が出ない端末では右上の 🎮 で出し入れできる。

## 調整ポイント

- `CAR_SPRITE` / `CAR_COLORS` … ⌐◨-◨カーのドット絵（30×19ドット、1文字=1ドット）と色。🚙 型の四駆の屋根に ⌐◨-◨ が乗っている

- `SCROLL` … 強制スクロールの速さ（ゾーンごと。px/フレーム）
- `PHYS` … 重力、跳ねる強さ、速度。長押ししたときの最大ジャンプは約230px、建物は最大200px
- `FUEL_DRAIN` … 燃料が減る速さ（満タンで約60秒）。燃料缶は `buildLevel()` の末尾
- `buildLevel()` … 地形・敵・コイン・CNPの配置。シードを変えると別のコースになる
- CNPはコースの奥や難所ほど高ランク（得点 100〜1500）のキャラを置いている
