# 咲耶ジャンプバグ（プロトタイプ）

レトロゲーム「ジャンプバグ」風の横スクロール。⌐◨-◨カーは地面や屋根に触れるたびに勝手に跳ねる。
CNPを拾いながらゴールの鳥居を目指す。公開URLは `https://sakuya.naoblock.jp/jumpbug/`。

- 単一ファイル（`index.html`）。画像は本家の `../assets/cnp/*.png`（CNP 11体）と `../image01.png`（咲耶の表情）を使う
- 音はWebAudioで生成しているので、音声ファイルは不要

## 操作

| 入力 | キーボード | タッチ |
| --- | --- | --- |
| 加速・減速 | ← → / A D | ◀ ▶ |
| ジャンプ（押している間は高く跳ぶ） | SPACE / ↑ / Z | JUMP |
| ショット | X | SHOT |
| 一時停止 / 音 | P / M | 右上のボタン |

## コース（固定シード `20260923`）

| ゾーン | x座標 | 内容 |
| --- | --- | --- |
| 城下町 | 0〜 | 町家の屋根を跳ね渡る。カラスと跳ねる鬼 |
| 忍びの洞窟 | 3600〜 | 溶岩の池、天井のトゲ、コウモリ |
| 天守 | 7400〜 | 3段の石垣を登り、堀は浮き足場で渡る（下からすり抜けられる）。天守の忍者は手裏剣を投げ、2発当てないと倒せない |
| 鳥居の丘 | 11200〜 | 鳥居（x=11950）をくぐったらゴール |

## 調整ポイント

- `PHYS` … 重力、跳ねる強さ、速度。長押ししたときの最大ジャンプは約230px、建物は最大200px
- `FUEL_DRAIN` … 燃料が減る速さ（満タンで約60秒）。燃料缶は `buildLevel()` の末尾
- `buildLevel()` … 地形・敵・コイン・CNPの配置。シードを変えると別のコースになる
- CNPはコースの奥や難所ほど高ランク（得点 100〜1500）のキャラを置いている
