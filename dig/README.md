# 咲耶ディグ（SAKUYA DIG）

城下町の地下を掘り進め、忍具と落石で敵をかわしながら、埋まった CNP 11体を掘り出して地上へ戻るブラウザゲーム。
咲耶シリーズの4作目です（姉妹作: [咲耶スクランブル](https://sakuya.naoblock.jp/) / [咲耶Nounラリー](https://rally.naoblock.jp/) / [咲耶ジャンプバグ](https://jumpbug.naoblock.jp/)）。

- 共通部分（操作・ポーズ・ランキング・CNP・結果画面など）は [sakuya-kit](https://github.com/naonao1971/sakuya-kit) を使っています
- 企画書: [docs/PLAN.md](docs/PLAN.md)

## 遊び方
- 地面を掘ると、その跡が通路になります。埋まっている CNP を掘り当てると救出
- 敵は忍具（長押し）で縛って倒すか、真下を掘って岩を落としてつぶします
- 11体そろえて地上の出口に戻るとクリア

## 操作
| | PC | スマホ（横持ち） |
|---|---|---|
| 移動（掘る） | 矢印 / WASD | 左半分のスティック |
| 忍具 | X（長押し） | 右下のボタン（長押し） |
| 一時停止 / 音 | P / M | 画面中央 / 🔊 |
