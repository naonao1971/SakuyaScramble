## ひとことで
城下町の地下を掘り進め、忍具と落石で敵をかわしながら、埋まった CNP 11体を掘り出して地上へ戻る。

## 遊び方
- 目的: 3層（城下町の地下 → 金山の坑道 → 天守の地下蔵）に埋まった CNP 11体を掘り出し、地上に戻る
- ミス: 敵に触れる／落ちてきた岩に当たる
- クリア: 11体そろえて地上の出口にたどり着く
- 1プレイの長さ: 3分くらい
- 難しさ: 最初の層はやさしく、深くなるほど敵が速く・多くなる

## 操作
| | PC | スマホ（横持ち） |
|---|---|---|
| 移動（掘る） | 矢印 / WASD（4方向） | 左半分のスティック（4方向） |
| ボタン1: 忍具 | X（長押しで縛りきる） | 右下の〇（長押し） |
| 一時停止 / 音 | P / M | 画面中央 / 🔊 |

- 岩は、真下を掘ると少し揺れてから落ちる（ボタンは使わない）
- 自動連射はなし

## CNP 11体
- 出し方: 各層の土の中に埋まっている（城下町の地下3体・金山の坑道4体・天守の地下蔵4体）。掘り当てると救出、ロスターが埋まる
- 全員そろえたとき: 地上の出口が開く。クリア時に全員救出ボーナス

## スコア
- 何で点が入るか:
  - 土を掘る: 1マス 10点
  - 忍具で倒す: 層ごとに 200 / 300 / 400点
  - 岩でつぶす: 1体 500点、2体まとめて 1,500点、3体以上 3,000点
  - CNP を掘り出す: 1体 300点
- ボーナス（クリア時、結果画面で内訳を見せる）: CNP 全員救出 5,000点＋残機 1機につき 1,000点
- 理論上の最高点（目安）: 掘る 約9,000＋敵 15体を岩で最大効率 約15,000＋CNP 3,300＋全員ボーナス 5,000＋残機 約3,000 ≒ 35,000点 → `maxScore`: 50,000（取りこぼしの余裕を見る）

## プロト v1 で入れたもの（2026-09-27）
- 盤面: 30x14 マス（1マス32px）。いちばん上は地上。掘った跡は咲耶の体の幅だけ削れ、平行の通路のあいだには壁が残る
- 3層: 城下町の地下（CNP 3・敵4・岩4）→ 金山の坑道（4・5・5）→ 天守の地下蔵（4・6・6）。層は毎回ランダムに作る
- CNP: 土の中の小さな空洞にうっすら見えている。その層の CNP をそろえると下への穴（▼）、最後の層では地上の出口（▲ EXIT）が開く
- 咲耶: 設定画をもとにした 12x14 ドットの絵（前・横・後ろ、歩き2コマ）。タイトル画面にも大きく出す
- 曲がりやすさ: 斜め入力（キー2つ・スティックを斜めに）で、升目の交点ごとに向きを入れ替えて1マスずつの階段に掘る。升目の線から 12px（約1/3マス）以内なら、手前でも通り過ぎていても角を斜めに切って曲がる（パックマン式。後ろへ戻る動きは出ない）
- 忍具: 長押しで向いている方へ縄（3.5マス、土は通らない）。敵に絡むと押している間に縛りが4段まで強まり、縛りきると倒せる。離すと少しずつほどける。縛られた敵には触れても平気
- 岩: 真下が掘れると揺れてから落ちる（咲耶が真下にいる間は待つ）。巻き込んだ敵の数で 500 / 1,500 / 3,000点
- 時間で速くなる: 30秒ごとに敵が1割ずつ速くなる（5段まで・層が変わると戻る）。左上に SPEED の目盛り
- 敵の絵: ぬばたまの妖怪（墨の玉・黒い炎・赤いひびと目、紫のふち）と忍者（黒装束・鉄の額当て・覆面、赤いふち）。どちらも前・横・後ろ・2コマ
- 敵: 通路を歩き、しばらくすると目だけの姿で土の中を抜けて近づいてくる（深い層ほど早い・速い）
- 忍者（層ごとに 1 / 2 / 3体）: 縦か横に4マス以内で並ぶと、0.3秒止まってから手裏剣を投げる。3マス飛び、土は抜けるが岩で止まる。当たるとミス。忍具の縄で叩き落とせる（50点）
- 忍具の縄は、押している間は張ったまま（土に当たったところで止まる）。張った縄に入ってきた敵も絡む
- まだ入れていないもの: BGM、結果画面のボーナス内訳、演出動画
