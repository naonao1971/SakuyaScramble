# Changelog

公開 API（`createKit` の設定、`kit` のプロパティ、CSS のクラス名とトークン）を壊す変更ではメジャー番号を上げる。
各タイトルはタグを固定して読み込んでいるので、タグを打ち直すことはしない。

## 0.1.0

- 咲耶スクランブルから共通部分を切り出して最初の版とした
  - コントローラー（キーボード、バーチャルスティック、ボタン、長押しトグル）
  - ジャイロ操作（既定は無効。`autoStart` で自動切り替え／トグルで任意に切り替えを選べる）
  - ポーズ、スタート、縦持ち案内、全画面／ホーム画面追加の案内
  - スコア登録フォーム、TOP10 ランキング（`?game=` でタイトル別のシートに分ける）
  - 総合ランキング（タイトルごとに1位比で1000点満点に揃えて合計、X ID で同じ人をまとめ、CNP は全タイトル分を合算）。`mountOverallRanking()` でゲームの無いページにも出せる
  - 登録したニックネームと X ID を次回のフォームに自動で入れる
  - CNP 11体の正典と画像、ランキングの救出ロスター
  - CLEAR / GAME OVER の演出動画（解錠、フォールバック、スキップ、ミュート連動）と共通の結果画面
  - タイトル名・OGP画像・アイコン・`<head>`・manifest.json を全タイトル同じ手順で差し替えるツール（`tools/ogp.html`）と、`<title>` のずれの警告。OGP 画像は既定で絵をそのまま使い、文字と枠を重ねる仕上げも選べる
  - 効果音エンジン、レトロ UI トークン、canvas 描画ヘルパー、シェア
- 3作（スクランブル・ラリー・ジャンプバグ）の読み比べから足したもの（`docs/INVENTORY.md`）
  - 自動連射（🔫 トグル方式／ボタンを短くタップで切り替える方式、V キー）、音の M キーと設定の保存
  - スティックを上に倒すとボタン、画面右半分の長押しでボタン、4方向スティックのぶれ防止
  - スコア（1UP・ハイスコア保存）、残機、チェックポイント、CNP の回収管理、HUD
  - ランキングの記録にクリア・進行度・CNP の体数を足し、GAS は列を見出しの名前で読み書きするようにした（旧版のシートをそのまま使える）。スコア上限のチェック
  - 権利表記のフッターは `cnp: true` のときだけ既定で出す（kit 本体はキャラに依存しない）
- 元の実装からの修正: ポーズ画面の「PAUSED」の色が未定義トークン（`RETRO.amber`）を参照していた問題を、金（`--gold`）に直した
