# 咲耶シリーズ ゲーム制作ルール

## 大原則

1. **共通部分は sakuya-kit に任せる。** コントローラー、ポーズ、スタート、縦持ち案内、スコア登録、ランキング、
   CNP キャラ、CLEAR / GAME OVER の演出動画と結果画面、全画面、効果音とミュート、シェアを、タイトル側で書き直したりコピーしたりしない。
   kit に足りない機能があれば、タイトル側に書かず kit 側に足す（下の「kit を直すとき」）。
2. **kit はバージョンを固定して読む。**
   `https://cdn.jsdelivr.net/gh/naonao1971/sakuya-kit@<版>/kit.js` と `kit.css`。`@latest` や `@main` は使わない。
3. **見た目で変えてよいのは色トークンだけ。** `kit.css` の後に `:root { --gold: ...; --magenta: ...; }` を書く。
   ボタンの寸法、配置、ベベル、フォントは変えない。canvas の色は `kit.retro.colors` から取り、色コードを直書きしない。
4. **タイトル側に書くのは `onStart` / `update` / `render` と、そのゲームにしかない描画・音・演出だけ。**

## 新作の手順

1. テンプレートリポジトリ（`sakuya-game-template`）から新しいリポジトリを作る
2. `gameId` を決める（英数字・`-`・`_`。ランキングのシート名になる。あとから変えない）
3. `index.html` の `createKit({...})` に、タイトル、ボタン、トグル、`cnp`、`share` を設定する
4. ゲーム本体を `update(kit)` / `render(ctx, kit)` に書く
   - 移動は `kit.input.axis()` を使う（キー、スティック、ジャイロが合成済み）
   - 傾き操作は既定で使わない。使うときは `controls.gyro` を指定する（自前で deviceorientation を扱わない）。
     傾きが主役のゲームは `true`、おまけなら `{ autoStart: false }`
   - 1プレイの終わりは必ず `kit.gameOver({ score, cleared, rescued })`
   - CNP を出すなら `kit.cnp.chars` と `kit.cnp.draw()`。救出キャラは `ch.no`（1始まり）で記録する
   - 結果画面と演出動画は kit に任せる。動画は `cutscenes: { clear: {src, image}, gameOver: {src} }` に渡すだけで、
     再生、飛ばす処理、ジングルへの切り替え、結果画面の描画は書かない。独自の飾りは `resultScreen.decorate` で足す
   - 定番の効果音は `kit.sfx.pickup()` などを使い、同じ意味の音はタイトル間でそろえる
5. `manifest.json`、アイコン、OGP、`CNAME` をタイトル用に書き換える
6. 共通 GAS の URL を `gasUrl` に入れる（新しい GAS は作らない）
7. 公開するときに、スプレッドシートの `_games` シートでそのタイトルの「総合に含める」を TRUE にし、
   「タイトル」列を正式名にする（総合ランキングに載る）。スコアは総合ランキングで他タイトルと 1位比で比べられるので、
   タイトル内で桁をそろえる必要はないが、公開後にスコアの付け方を大きく変えない

## 画面の約束（全タイトル共通）

- canvas は 960x540、横持ち前提。縦持ちでは kit が案内を出してゲームを止める
- タイトル画面は `kit.retro.titleText(主題, 副題)`（主題は金、副題はマゼンタ）
- 結果のテロップは `kit.retro.caption()`
- 走査線 `kit.retro.crt()` は背景と地形にだけ敷き、キャラやイラストの上には描かない
- 権利表記（非公式ファンアート）は kit のフッターのまま残す

## 公開前の確認

- [ ] PC: 矢印 / WASD で移動、P でポーズ、Enter / Space でスタート
- [ ] スマホ横持ち: 左半分のスティック、右下のボタン、長押しトグル（🔊 ⛶ 🕹️）
- [ ] ジャイロを使うタイトル: iPhone で許可ダイアログが出る。🕹️/📱 の長押しで切り替わる
- [ ] スマホ縦持ち: 案内が出て、ゲームが止まる
- [ ] iPhone: 初回スタートで効果音が鳴る。ジャイロ許可ダイアログのあとも鳴る
- [ ] ゲームオーバー動画がタップで飛ばせる。クリア動画は流し終えると静止画に戻る。🔊 オフで動画も無音になる
- [ ] 動画を置かない / 読み込めない状態でも、ジングルと結果画面が出る
- [ ] ゲームオーバー / クリア → TOP10 なら登録フォーム → 登録 → ランキングに反映
- [ ] 一時停止中にタブを切り替えて戻っても、入力が押しっぱなしにならない

## kit を直すとき

- 修正は sakuya-kit リポジトリで行い、`demo/` で動作を確かめてから新しいタグを打つ
- 既存の API を壊す変更はメジャー番号を上げ、`CHANGELOG.md` に移行方法を書く
- 各タイトルへの反映は、そのタイトルの読み込み URL の版番号を上げ、実機で確認してから行う
