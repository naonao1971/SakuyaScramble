# CNP 救出対象アセット

咲耶スクランブルの洞窟内を浮遊する「救出対象」に使う画像の置き場所。

## 置き方

このディレクトリに以下のファイル名で置くと、コード変更なしで反映される。

```
cnp01.png  cnp02.png  cnp03.png  cnp04.png  cnp05.png  cnp06.png
cnp07.png  cnp08.png  cnp09.png  cnp10.png  cnp11.png
```

ファイルが無いスロットは、`index.html` の `drawCnpPlaceholder()` が描く
色付きシルエット（「?」入り）で代替される。画像が1枚も無くても、浮遊・
当たり判定・救出演出はすべて動く。

## 画像の仕様

| 項目 | 推奨 |
| --- | --- |
| 形式 | PNG（**背景透過必須**） |
| サイズ | 128×128 または 256×256 の正方形 |
| 余白 | キャラの周囲の透明余白は詰めておく |
| 向き | 正面〜やや左向き（機体は右へ進むため） |

背景が透過されていない元画像しか無い場合は、`tools/make_rescue_assets.py`
で単色背景の切り抜き・正方形化・余白トリムができる。

## 表示サイズと出現率

描画サイズ・当たり判定・全体の出現率は `index.html` の `CNP_RESCUE`。

```js
const CNP_RESCUE = {
  size: 60,          // 描画サイズ(px四方)
  radius: 20,        // 当たり判定
  spawnChance: 0.0011
};
```

## レア度と得点

得点は `CNP_TIERS` の5段階。得点が高い段ほど `weight` を下げてあり、
高得点キャラほど出にくい。

| rank | 得点 | HP回復 | 出現率 |
| --- | --- | --- | --- |
| 1 | 100 | +4 | 59.3% |
| 2 | 200 | +6 | 27.5% |
| 3 | 400 | +8 | 10.3% |
| 4 | 800 | +10 | 2.3% |
| 5 | 1500 | +14 | 0.6% |

出現率は weight から決まる実測値（全キャラ合計 175 に対する各段の比率）。
`weight` を変えれば連動して変わる。

ただし**まだ収集していないキャラは重みが `CNP_UNCOLLECTED_BOOST` 倍（既定5倍）**
になる。上の表は全員収集済みのときの値で、収集途中は未収集キャラがこれより
出やすい。優遇が無いと11体制覇に中央値17プレイかかるため（最上位が0.57%）。

どのキャラを何点にするかは `cnpChars` の `tier`（`CNP_TIERS` の添字、0始まり）
で決まる。初期配分は rank1 が4体、rank2 が3体、rank3 が2体、rank4 と rank5 が
1体ずつ。

```js
const cnpChars = [
  { hue: 196, tier: 0 },   // cnp01 -> rank1 / 100点
  ...
  { hue: 352, tier: 4 }    // cnp11 -> rank5 / 1500点
];
```

レア度はゲーム画面上でも読める。キャラの足元に rank の数だけ菱形のピップが
並び、背後のオーラは rank が上がるほど広く濃くなる。rank4 以上には逆回転の
外周リングが追加される。

## 上段の額縁ロスター

画面上段に11体ぶんの額縁が並び、そのプレイで誰を救出済みかが常時見える。

- **未収集** … 黒いシルエット + 減光した琥珀の枠
- **収集済み（通算）** … 絵を落として表示 + くすんだキャラ色の枠
- **今回のプレイで救出** … 絵を全光量で表示 + キャラ色の枠
- **救出した瞬間** … その額が45フレームだけ白く光る
- 額の下に `6 / 11` の収集率（通算）。全員そろうと `COMPLETE!` が点滅する

収集状況（`state.collected`）はリスタートをまたいで残るが、**保存はしていない**
ので、リロードやタブを閉じるとリセットされる。1プレイ約2分では平均6.5種類しか
集まらない（制覇率0.35%）ため、制覇は同じタブで続けて遊んで狙う設計。中央値
5プレイ、9割が12プレイ以内で達成する。

保存を有効にする場合は、`state.collected` を localStorage に読み書きする処理を
足す（リロードをまたいで残るようになる）。配置と寸法は
`CNP_ROSTER` で調整できる。左の SCORE、右の HP バー、下のキャプション枠の
いずれにも触れない寸法にしてあるので、`slot` を大きくする場合はその3つとの
間隔を確認すること。

```js
const CNP_ROSTER = {
  slot: 36,          // 額1枚の一辺
  gap: 4,
  y: 10,
  flash: 45          // 救出した瞬間に額が光るフレーム数
};
```

## キャラ名の差し替え

救出時のボーナス表示に出る名前は `index.html` の `cnpChars` の `label`。
初期値は `CNP01`〜`CNP11` なので、正式なキャラ名に書き換える。ファイル名も
合わせて変える場合は `id` も同時に変更する（`id` がそのまま
`assets/cnp/<id>.png` を指す）。

`hue` はプレースホルダの色と、キャラ背後に出る浮遊オーラ／救出リングの色に
使われる。画像を置いた後もオーラの色として効き続けるので、キャラのイメージ
カラーに合わせておくと馴染む。
